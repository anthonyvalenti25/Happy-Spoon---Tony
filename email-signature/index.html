Gmail

  1. Click Copy signature above.
  2. In Gmail, open Settings (gear) → See all settings → General.
  3. Scroll to Signature, click Create new, and paste into the box.
  4. Choose it under Signature defaults, then Save Changes at the bottom.

Apple Mail (Mac)

  1. Open this page in Safari and click Copy signature.
  2. In Mail, go to Settings → Signatures, pick the account, and click +.
  3. Untick Always match my default message font, then paste into the preview area.

iPhone Mail

  1. Open this page on the phone, long-press to select the signature, and copy it.
  2. Go to Settings → Apps → Mail → Signature and paste.

Outlook and others

  1. Paste with Copy signature into the signature editor, or use Copy HTML code if the app accepts HTML.
